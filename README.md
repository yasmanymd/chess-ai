# AI-Assisted Chess Platform

This directory is the portable documentation foundation for a new, public, AI-assisted software project.

The project has two complementary goals:

1. Build a usable, multilingual, web-based multiplayer chess platform with future educational capabilities.
2. Publish a transparent case study of modern software development performed with AI and agent assistance.

The directory currently lives inside the legacy `chess-sol` repository only as a staging area. It is intended to become the root of a new standalone repository. Its internal paths are therefore relative and do not depend on the legacy project.
