# AI-Assisted Development Records

This area records how humans, AI models, tools, and agents contribute to the project.

## Contents

- [`working-agreement.md`](working-agreement.md): collaboration and approval rules.
- [`sessions/`](sessions/): chronological work records.
- [`prompts/`](prompts/): selected prompts worth preserving verbatim.
- [`experiments/`](experiments/): hypothesis-driven technical experiments.
- [`evaluations/`](evaluations/): structured assessments of generated outputs.

Routine conversational noise is not preserved. Records should capture the information necessary to understand decisions, reproduce important work, and learn from mistakes.
