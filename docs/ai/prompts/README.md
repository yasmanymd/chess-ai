# Selected Prompts

This directory stores only prompts and responses with durable educational, reproducibility, or audit value.

Complete conversational transcripts are not stored by default. Each preserved prompt should state:

- Why it was selected.
- Session ID.
- Date.
- Human author or initiating role.
- Model, tool, and agent when known.
- Whether the text is complete or excerpted.
- The outcome it influenced.

Use [`../../templates/prompt-record-template.md`](../../templates/prompt-record-template.md).
